# Smart Canteen Management System

A Python-based mini project that analyzes canteen order data and presents meaningful insights through an interactive graphical user interface.

## Project Overview

The Smart Canteen Management System helps analyze canteen orders, sales, revenue, and popular food items. It uses data analysis and visualization techniques to convert order records into useful information for understanding canteen performance.

##  Objectives

- Analyze canteen order records.
- Calculate sales and revenue.
- Identify popular food items.
- Present insights using charts and graphs.
- Provide a simple and user-friendly graphical interface.

##  Features

- Interactive graphical user interface.
- Canteen order data analysis.
- Sales and revenue analysis.
- Popular food item identification.
- Data visualization using charts.
- CSV dataset support.
- Easy-to-understand analytical results.

##  Technologies Used

- **Python** – Main programming language
- **Tkinter** – Graphical user interface
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **CSV** – Data storage

##  Installation and Setup

### 1. Install Python

Download Python from [python.org](https://www.python.org/downloads/).

### 2. Clone the Repository

```bash
git clone https://github.com/khushi-mahajan1/Smart-canteen-management-system.git
```

### 3. Open the Project Folder

```bash
cd Smart-canteen-management-system
```

### 4. Install Required Libraries

```bash
pip install pandas numpy matplotlib
```

Tkinter is generally included with the standard Windows Python installation.

### 5. Run the Project

```bash
python main.py
```

Make sure the Python filename and dataset path match the files in your project.

##  Dataset

The project uses a CSV dataset containing canteen order information, such as:

- Order ID
- Student ID
- Food item
- Quantity
- Price per item
- Order date
- Time slot

The dataset is used to perform calculations and generate visualizations.
